Nestcoin is an African fintech company building Onboard, a digital-money platform and crypto exchange for on/off-ramping between fiat and crypto. Its developer product, Onboard Connect, is the SDK & API integration layer over Onboard Exchange, giving Web2 and Web3 builders access to a ready-made peer-to-peer marketplace, liquidity, offers/pricing, orders, beneficiaries, and payout accounts. The public Onboard External API Gateway (OpenAPI 3.0.3, v3.0.2) exposes 96 operations across users/auth, offers, orders, accounts, and webhooks, secured with API keys, session tokens, and HMAC-SHA256 request signing. Nestcoin is backed by Coinbase Ventures, Base Ecosystem, HashKey Capital, Hashed Emergent, Distributed Global, Electric Capital, and others.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Nestcoin: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
